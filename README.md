# 🛰️ PC Performance Monitor

**LibreHardwareMonitorLib と独自 C++ DLL を統合した高精度システム監視ツール**

このツールは、CPUの温度、クロック、電圧、およびシステム全体のメモリやプロセス情報をリアルタイムで監視・ログ保存するための Python アプリケーションです。

## ✨ 主要機能

### 1. リアルタイム・ハードウェア・モニタリング

* **CPU詳細情報**: `LibreHardwareMonitorLib.dll` を介して、各論理プロセッサ（LP）ごとの使用率、クロック、温度、電圧を取得します。
* **サーマルスロットリング監視**: CPUが熱による制限を受けているかをリアルタイムで判定します。
* **メモリ・スワップ監視**: 物理メモリおよびスワップ領域の使用状況をゲージで表示します。

### 2. 高度なデータロギング

* **4種類のログモード**:
* **Fast System Log**: システム全体の高速ログ。
* **Core Details Log**: 各コアの詳細なステータス。
* **Active Detail Log**: アクティブなプロセスの詳細。
* **Periodic Snapshot**: 定期的なシステムスナップショット。


* **変化時のみ記録**: CPUのステータスに変化があった時のみログに書き込む「Log on change」機能を搭載し、ログファイルの肥大化を抑えます。

### 3. プロセス解析

* **Top Processes**: CPU使用率およびメモリ使用量の多い上位プロセスをそれぞれ抽出して表示します。

## 🛠️ セットアップ

### 必須コンポーネント

1. **DLLs フォルダ**: 実行ファイルと同じディレクトリに `DLLs` フォルダを作成し、以下のファイルを配置してください。
* `LibreHardwareMonitorLib.dll`
* `pcmonitor.dll`
* `getcoreinfo.dll`



### インストール

```bash
pip install -r requirements.txt

```

## 📖 開発者向け情報（デバッグ・ログ）

現在、正式版リリース前の開発フェーズとして以下の仕様が適用されています。

* **イミディエイトウィンドウ出力**: ツール実行中のエラー（DLLロード失敗、センサー取得エラー等）や重要なステータス変化は、コンソール（イミディエイトウィンドウ）にタイムスタンプ付きで出力されます。
* **センサー名の調査**: `corename.py` を単体で実行することで、接続されているCPUの温度センサー名を一覧表示し、正しく認識されているかを確認できます。

## ⚠️ 注意事項

* このツールはハードウェア情報にアクセスするため、管理者権限での実行が必要になる場合があります。
